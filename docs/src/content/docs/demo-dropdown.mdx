## Features

<Steps>
1. **Interactive Dropdown:** Tap the title bar in the preview to see the TOC sections.
2. **Progress Indicator:** The circle around the current section title updates as you scroll.
3. **Glassmorphism:** The dropdown menu and title bar use a translucent blur effect.
</Steps>

## How to Enable

Add this to your `astro.config.mjs`:

```js
starlightGlide({
  mobile: 'dropdown',
  glassmorphism: true,
})
```
