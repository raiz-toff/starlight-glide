## Mobile View

<Steps>
1. **No Dropdown:** Unlike the default mobile view, the minimal preset only shows a progress bar and the current heading.
2. **Snap Physics:** The desktop indicator (if visible) will instantly jump to the active section without animation.
3. **Screen Space:** This saves valuable vertical screen real estate on small devices.
</Steps>
