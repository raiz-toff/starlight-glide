This page demonstrates the **starlight-glide** plugin in action with the `dot` desktop preset and `spring` physics <Badge text="Spring Physics" variant="caution" />. Scroll down to see the glowing dot bounce along the track as you progress. We've also overridden the indicator color on this page.

## Bouncy Movement

<Steps>
1. **Spring Physics:** Notice the slight bounce when you scroll between sections!
2. **Minimalist Design:** The dot tracks your vertical progress without expanding horizontally.
3. **Custom Color:** We used the frontmatter config to change the color to red for this specific page.
</Steps>
