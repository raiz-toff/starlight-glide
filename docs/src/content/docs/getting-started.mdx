## Prerequisites

You will need to have a Starlight website set up.
If you don't have one yet, you can follow the ["Getting Started"](https://starlight.astro.build/getting-started) guide in the Starlight docs to create one.

## Installation

import { Steps, Tabs, TabItem } from '@astrojs/starlight/components'

<Steps>

1. `starlight-glide` is a Starlight [plugin](https://starlight.astro.build/reference/plugins/). Install it by running the following command in your terminal:

   <Tabs syncKey="pkg">

   <TabItem label="npm">

   ```sh
   npm install starlight-glide
   ```

   </TabItem>

   <TabItem label="pnpm">

   ```sh
   pnpm add starlight-glide
   ```

   </TabItem>

   <TabItem label="Yarn">

   ```sh
   yarn add starlight-glide
   ```

   </TabItem>

   </Tabs>

2. Configure the plugin in your Starlight [configuration](https://starlight.astro.build/reference/configuration/#plugins) in the `astro.config.mjs` file.

   ```diff lang="js"
   // astro.config.mjs
   import starlight from '@astrojs/starlight'
   import { defineConfig } from 'astro/config'
   +import starlightGlide from 'starlight-glide'

   export default defineConfig({
     integrations: [
       starlight({
   +      plugins: [starlightGlide()],
         title: 'My Docs',
       }),
     ],
   })
   ```

3. **(Optional)** Customize the plugin. By default, the TOC uses your theme's accent colors. You can customize the header text, colors, and the "snake" path depth via the plugin options:

   ```diff lang="js"
   // astro.config.mjs
   export default defineConfig({
     integrations: [
       starlight({
         plugins: [
           starlightGlide({
   +          headerText: 'On this page',
   +          indicatorColor: 'var(--sl-color-accent)',
   +          glassmorphism: true,
            })
          ],
        }),
      ],
    })
   ```

   Check out the [Configuration guide](/configuration/) for a full list of available options.

4. [Start the development server](https://starlight.astro.build/getting-started/#start-the-development-server) to preview the plugin in action.

</Steps>
