## Navigation that feels like Magic

Standard documentation can feel static. `starlight-glide` brings your Table of Contents to life with fluid, high-performance animations that guide your users as they scroll.

### Built for Every Theme
Stop worrying about CSS conflicts. Our **Decoupled Architecture** creates a private styling namespace (`--glide-`) that intelligently "listens" to your site's colors. Whether you use the standard Starlight theme, the sleek **Rapide** theme, or a completely custom design, Glide adapts instantly.

### Modular by Design
Don't settle for one-size-fits-all.
- **On Desktop:** Choose the "Snake" for a fluid, organic path, or the "Dot" for a minimal, precision-focused indicator.
- **On Mobile:** Keep it light with the "Minimal" bar or go full-featured with the glassmorphic "Dropdown" menu.

:::tip[Performance First]
Glide is built with performance as a priority. All animations use hardware-accelerated CSS transforms and lightweight SVG paths, ensuring a smooth experience even on low-end mobile devices.
:::
